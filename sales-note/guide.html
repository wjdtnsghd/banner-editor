영업노트 가이드

통화·미팅이 끝나면 30초 안에 가망건을 저장하고, 저장한 업체에 이메일·카톡·문자를 바로 보내는 팀 공용 웹앱입니다. PC와 휴대폰 어디서나 회사 구글 계정으로 씁니다.

신입 사용법 팀장 확인 방법 처음 설치 (관리자 1회) 문제 해결

신입 사용법

매일 쓰는 사람을 위한 안내

시작하기

  1. 팀장에게 받은 영업노트 링크를 휴대폰과 PC에서 엽니다. 회사 구글 계정(@mymp.co.kr)으로 로그인되어 있어야 합니다.
  2. 처음 열면 권한 승인 창이 뜹니다. 계정 선택 → 허용을 누르세요. (내 Gmail로 메일을 보내고 팀 시트에 저장하기 위한 권한입니다)
  3. 이름을 입력합니다. 메일·카톡 문구의 {영업자} 자리와 팀 현황에 이 이름이 들어갑니다.
  4. 휴대폰 홈 화면에 추가해 두면 앱처럼 바로 열 수 있습니다.
    • 안드로이드(크롬): 오른쪽 위 ⋮ → 홈 화면에 추가
    • 아이폰(사파리): 아래 공유 버튼 → 홈 화면에 추가

하루 루틴

출근 후오늘 탭 확인"오늘 연락할 곳"부터 연락합니다. 날짜가 지난 곳은 빨간색 '밀림'으로 표시됩니다.
통화·미팅 직후+ 가망건 저장업체명만 필수. 가망도와 다음 연락일만 눌러 두면 됩니다.
저장 직후바로 메일·카톡저장하면 뜨는 "바로 메일 보내기"로 자료를 이어서 보냅니다.
퇴근 전도장 5개 채우기상단 도장이 하루 목표(5건)입니다. 매일 저장하면 연속 기록이 쌓입니다.

가망건 저장 요령

항목이렇게 쓰세요
가망도상 구체적 관심·예산 언급 / 중 자료 받아보겠다 / 하 당장은 관심 없음
상태신규 → 연락중 → 제안발송 → 미팅 → 계약 (보류·종료). 이메일을 보내면 '신규'는 자동으로 '연락중'이 됩니다.
다음 연락일꼭 정해 두세요. 이 날짜가 되면 '오늘' 탭에 자동으로 올라옵니다.
메모현재 광고 상황, 불만, 예산, 결정권자, 다음에 할 말 등. 나중에 재통화할 때 큰 도움이 됩니다.

이메일 보내기

  1. 목록에서 보낼 업체의 체크박스를 누릅니다(여러 곳 가능). 아래에 이메일 보내기 버튼이 나타납니다.
  2. 템플릿을 고르고 필요하면 내용을 고칩니다. {업체명} {담당자} {영업자}는 업체마다 자동으로 바뀝니다.
  3. 첨부 파일(제안서 등)을 추가하고 N곳에 보내기. 업체마다 한 통씩 따로 나가며, 내 Gmail 보낸편지함에 남습니다.
앱 비밀번호 같은 별도 설정은 필요 없습니다. 내 회사 Gmail에서 그대로 발송됩니다.

카톡·문자 보내기

  1. 업체를 눌러 상세 화면 → 카톡·문자.
  2. 문구가 업체에 맞게 자동으로 채워집니다. 문구 복사 → 카카오톡 열기 → 대화방에 붙여넣어 보냅니다.
  3. 휴대폰에서는 문자로 바로 보내기를 누르면 문구가 들어간 문자 앱이 열립니다.
카카오톡은 카카오 정책상 개인 카톡 자동 발송이 불가능해 '복사 → 붙여넣기' 방식입니다. 복사·문자·전화 걸기를 누르면 연락 기록에 자동으로 남습니다.

통화 기록

상세 화면 → 통화 기록에 한 줄 메모와 다음 연락일을 남기세요. 업체별 연락 기록이 시간순으로 쌓여, 누가 언제 무슨 얘기를 했는지 한눈에 보입니다.

팀장 확인 방법

신입들의 저장 습관과 가망건 현황 보기

볼 수 있는 것

  • 팀 현황 탭: 누가 오늘 몇 건 저장했는지, 연락이 밀린 가망건이 몇 개인지
  • 가망건 목록 → 팀 전체: 팀 전체 가망건을 검색·필터. 업체를 누르면 연락 기록까지 확인
  • 구글 시트 원본: 엑셀처럼 정렬·필터·다운로드 가능 (가망건, 연락이력, 사용자 탭)

템플릿 바꾸기

구글 시트의 템플릿 탭에서 행을 추가·수정하면 바로 반영됩니다. 유형은 이메일 또는 카톡, 본문에 {업체명} {담당자} {영업자}를 쓸 수 있습니다.

하루 목표 바꾸기

Apps Script의 Code.gs 맨 위 DAILY_GOAL = 5 숫자를 바꾸고 새 버전으로 배포합니다.

처음 설치

관리자 1명이 한 번만 · 약 10분 · 준비물: Code.gs, Index.html 파일

  1. 구글 드라이브에서 새로 만들기 → Google 스프레드시트. 이름을 영업노트_DB로 정합니다. (팀 데이터가 저장될 곳)
  2. 시트 메뉴 확장 프로그램 → Apps Script를 엽니다.
  3. 왼쪽 Code.gs의 기존 내용을 모두 지우고, 받은 Code.gs 파일 내용을 붙여넣습니다.
  4. 파일 옆 + → HTML → 이름을 Index로 입력(확장자 없이) → 받은 Index.html 내용을 붙여넣습니다.
  5. 💾 저장 후, 위쪽 함수 선택에서 getInitialData를 고르고 실행 → 권한 검토 → 허용. 시트에 가망건·연락이력·템플릿·사용자 탭이 생기면 성공입니다.
  6. 오른쪽 위 배포 → 새 배포 → 톱니바퀴에서 웹 앱 선택 후:
    • 실행 사용자: 웹 앱에 액세스하는 사용자 (그래야 각자 본인 Gmail로 발송됩니다)
    • 액세스 권한: mymp.co.kr 내 모든 사용자
    배포를 누르고 나오는 웹 앱 URL을 복사합니다.
  7. 영업노트_DB 시트를 팀원들에게 편집자로 공유합니다. (각자 계정으로 실행되므로 시트 편집 권한이 있어야 저장됩니다)
  8. 복사한 웹 앱 URL과 이 가이드를 팀원에게 전달합니다.
코드를 수정한 뒤에는 배포 → 배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포. 이렇게 해야 같은 링크에 반영됩니다. (새 배포를 만들면 링크가 바뀝니다)
팀원이 시트 편집 권한을 가지므로 원본 시트를 직접 열어 볼 수 있습니다. 팀 공용 영업 데이터라는 점을 안내해 주세요.

문제 해결

증상해결
"액세스 권한 필요" / 열리지 않음회사 계정(@mymp.co.kr)으로 로그인했는지 확인. 개인 Gmail로 로그인되어 있으면 계정을 전환하세요.
저장할 때 권한 오류영업노트_DB 시트가 본인에게 편집자로 공유되었는지 관리자에게 확인하세요.
"이 앱은 Google에서 확인하지 않았습니다"사내에서 만든 앱이라 나오는 안내입니다. 고급 → 영업노트(으)로 이동을 누르세요. 회사 관리자가 막아 두었다면 관리자에게 허용을 요청합니다.
메일 발송 실패 "남은 발송 가능 건수"구글 정책상 하루 약 1,500통까지 보낼 수 있습니다. 다음 날 나눠서 보내세요.
카톡 문구 복사가 안 됨일부 브라우저에서 복사가 막힐 수 있습니다. 내용 칸을 길게 눌러 전체 선택 → 복사하세요.
휴대폰에서 '문자로 바로 보내기'가 안 보임업체에 연락처가 저장되어 있어야 나타납니다. PC에서는 표시되지 않습니다.
