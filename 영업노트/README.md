# 영업노트

통화·미팅 직후 가망건을 저장하고, 저장한 업체에 이메일·카톡·문자를 바로 보내는 팀 공용 웹앱 (Google Apps Script + Google 스프레드시트).

| 파일 | 설명 |
| --- | --- |
| `Code.gs` | 서버 코드: 시트 저장, 연락 기록, 삭제, Gmail 발송 |
| `Index.html` | 화면: 오늘 / 가망건 목록 / 팀 현황, 저장·상세·이메일·카톡 창 |
| `guide.html` | 팀원 가이드: 처음 설정, 하루 사용법, 이메일·카톡, 문제 해결 |
| `설정가이드.html` | 관리자 설정 가이드: 설치, 코드 업데이트, 설정 변경, 팀원 공유 |

## 주요 기능

- 가망건 저장: 업체명만 필수. 가망도(상·중·하), 상태, 다음 연락일, 연락 시간, 메모
- 오늘 탭: 오늘 연락할 곳(밀림 표시), 오늘 저장한 곳, 이번 주 연락 예정
- 하루 목표 도장(기본 5건)과 연속 저장 기록
- 이메일: 내 회사 Gmail에서 업체마다 한 통씩 발송, 첨부 가능. 한 곳에 보낼 때는 업체 정보가 바로 채워짐. 보내는 사람·받는 사람 표시와 기록
- 카톡·문자: 업체 맞춤 문구 복사, 휴대폰 문자 앱 바로 열기
- 상세: 전화 걸기, 통화 기록, 상태 변경, 수정, 삭제(연락 기록 포함)
- 팀 현황: 팀원별 오늘·7일 저장, 진행 중, 가망 상, 연락 밀림, 계약

## 설치 요약 (자세한 내용은 `설정가이드.html`)

1. 스프레드시트 `영업노트_DB` 생성 → 확장 프로그램 → Apps Script
2. `Code.gs` 붙여넣기, 파일 옆 **+ → HTML** 로 `Index` 만들고 `Index.html` 붙여넣기
3. 함수 `getInitialData` 선택 후 실행 → 권한 허용 → `가망건`·`연락이력`·`템플릿`·`사용자` 탭 생성 확인
4. 배포 → 새 배포 → 웹 앱
   - 실행 사용자: **웹 앱을 액세스하는 사용자**
   - 액세스 권한: **mymp.co.kr 내 모든 사용자**
5. 시트를 팀원에게 **편집자**로 공유하고 웹 앱 URL과 `guide.html` 전달

코드 수정 후에는 **배포 관리 → ✏️ 수정 → 버전: 새 버전 → 배포**. 새 배포를 만들면 링크가 바뀝니다. 새 버전에서 추가된 시트 열(예: `연락시간`)은 앱을 열 때 자동으로 추가됩니다.

## 설정

`Code.gs` 맨 위:

- `DAILY_GOAL`: 하루 저장 목표(도장 수), 기본 5
- `COMPANY_NAME`: 기본 템플릿과 보내는 사람 이름에 쓰이는 회사명
- `SPREADSHEET_ID`: 비워 두면 스크립트가 붙은 시트를 사용

템플릿은 시트의 `템플릿` 탭에서 바로 수정합니다 (유형: `이메일` / `카톡`, 본문에 `{업체명}` `{담당자}` `{영업자}` 사용).
