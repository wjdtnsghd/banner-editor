# 영업노트

통화·미팅 직후 가망건을 저장하고, 저장한 업체에 이메일·카톡·문자를 바로 보내는 팀 공용 웹앱 (Google Apps Script + Google 스프레드시트).

| 파일 | 설명 |
| --- | --- |
| `Code.gs` | 서버 코드 — 시트 저장, 연락 기록, Gmail 발송 |
| `Index.html` | 화면 — 오늘 / 가망건 목록 / 팀 현황, 저장·이메일·카톡 시트 |
| `guide.html` | 사용·설치 가이드 (팀원 배포용) |

## 설치 (관리자 1회, 약 10분)

1. 구글 드라이브 → 새 스프레드시트 `영업노트_DB` 생성
2. 확장 프로그램 → Apps Script → `Code.gs` 내용 붙여넣기, HTML 파일 `Index` 추가 후 `Index.html` 붙여넣기
3. 함수 `getInitialData` 실행 → 권한 허용 → `가망건`·`연락이력`·`템플릿`·`사용자` 탭 생성 확인
4. 배포 → 새 배포 → 웹 앱
   - 실행 사용자: **웹 앱에 액세스하는 사용자**
   - 액세스 권한: **mymp.co.kr 내 모든 사용자**
5. 시트를 팀원에게 **편집자**로 공유하고 웹 앱 URL 전달

코드 수정 후에는 배포 관리 → 수정 → 버전 **새 버전**으로 배포해야 같은 링크에 반영됩니다.

## 설정

`Code.gs` 맨 위:

- `DAILY_GOAL` — 하루 저장 목표(도장 수), 기본 5
- `COMPANY_NAME` — 기본 템플릿과 보내는 사람 이름에 쓰이는 회사명
- `SPREADSHEET_ID` — 비워 두면 스크립트가 붙은 시트를 사용

템플릿은 시트의 `템플릿` 탭에서 바로 수정합니다 (유형: `이메일` / `카톡`, 본문에 `{업체명}` `{담당자}` `{영업자}` 사용).
