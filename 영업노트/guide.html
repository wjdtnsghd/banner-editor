영업노트 가이드

통화·미팅이 끝나면 30초 안에 가망건을 저장하고, 저장한 업체에 이메일·카톡·문자를 바로 보내는 팀 공용 웹앱입니다. PC와 휴대폰 어디서나 회사 구글 계정으로 씁니다.

처음 설정 (5분) 하루 사용법 이메일 카톡·문자 팀장 확인 문제 해결 관리자 설정 가이드 →

처음 설정

팀원 한 명당 한 번만 · 약 5분 · 준비물: 팀장에게 받은 영업노트 링크

  1. 회사 계정으로 로그인: 크롬(PC) 또는 휴대폰 브라우저가 회사 구글 계정(@mymp.co.kr)으로 로그인되어 있는지 확인합니다. 개인 Gmail로 로그인되어 있으면 열리지 않습니다.
  2. 링크 열기: 받은 링크(https://script.google.com/a/macros/mymp.co.kr/s/…/exec)를 엽니다.
  3. 권한 승인: 처음 한 번 "승인 필요" 창이 뜹니다.
    • 권한 검토 → 회사 계정 선택
    • "Google에서 확인하지 않은 앱"이 나오면 고급 → 영업노트(으)로 이동. 사내에서 만든 앱이라 나오는 안내입니다.
    • 허용. 내 Gmail로 메일을 보내고 팀 시트에 저장하기 위한 권한입니다.
  4. 이름 입력: 메일·카톡 문구의 {영업자} 자리와 팀 현황에 이 이름이 들어갑니다. 나중에 오른쪽 위 "○○○ 님"을 눌러 바꿀 수 있습니다.
  5. 휴대폰 홈 화면에 추가: 앱처럼 바로 열 수 있습니다.
    • 안드로이드(크롬): 오른쪽 위 ⋮ → 홈 화면에 추가
    • 아이폰(사파리): 아래 공유 버튼 → 홈 화면에 추가
  6. 테스트 저장: + 가망건 저장으로 아무 업체나 하나 저장해 봅니다. 상단 도장 1개가 채워지면 설정 완료입니다. 테스트한 건은 상세 화면의 삭제로 지우면 됩니다.
저장할 때 권한 오류가 나면 영업노트_DB 시트가 내 계정에 편집자로 공유되어 있지 않은 것입니다. 팀장(관리자)에게 공유를 요청하세요.

하루 사용법

매일 쓰는 흐름

출근 후오늘 탭 확인"오늘 연락할 곳"부터 연락합니다. 날짜가 지난 곳은 빨간색 '밀림'으로 표시됩니다.
통화·미팅 직후+ 가망건 저장업체명만 필수. 가망도, 다음 연락일, 연락 시간만 눌러 두면 됩니다.
저장 직후바로 메일·카톡저장하면 뜨는 "바로 메일 보내기"로 자료를 이어서 보냅니다.
퇴근 전도장 5개 채우기상단 도장이 하루 목표(5건)입니다. 매일 저장하면 연속 기록이 쌓입니다.

가망건 저장 요령

항목이렇게 쓰세요
가망도상 구체적 관심·예산 언급 / 중 자료 받아보겠다 / 하 당장은 관심 없음
상태신규 → 연락중 → 제안발송 → 미팅 → 계약 (보류·종료). 이메일을 보내면 '신규'는 자동으로 '연락중'이 됩니다.
다음 연락일꼭 정해 두세요. 이 날짜가 되면 '오늘' 탭에 자동으로 올라옵니다.
연락 시간약속한 시간이 있으면 선택(오전 10시·오후 2시·오후 4시 또는 직접 입력). 목록에 "오늘 연락 14:00"처럼 보이고, 같은 날이면 이른 시간 순으로 정렬됩니다.
메모현재 광고 상황, 불만, 예산, 결정권자, 다음에 할 말 등. 재통화할 때 큰 도움이 됩니다.

업체 상세 화면

목록에서 업체 이름을 누르면 상세 화면이 열립니다.

  • 통화 기록: 한 줄 메모와 다음 연락일·시간을 남기면 업체별 연락 기록이 시간순으로 쌓입니다.
  • 상태 바꾸기: 버튼 한 번으로 바로 저장됩니다.
  • 전화 걸기·문구 복사·문자를 누르면 연락 기록에 자동으로 남습니다.
  • 삭제: 확인 창이 한 번 더 뜨고, 연락 기록까지 함께 지워집니다. 되돌릴 수 없으니 거래가 끝난 곳은 상태를 종료로 바꾸는 것을 권장합니다.

여러 곳을 한꺼번에 지우려면 목록에서 체크한 뒤 아래 바의 삭제를 누릅니다.

이메일 보내기

내 회사 Gmail에서 업체마다 한 통씩 발송

  1. 목록에서 보낼 업체의 체크박스를 누릅니다(여러 곳 가능). 아래에 이메일 보내기가 나타납니다. 상세 화면의 이메일 버튼으로도 됩니다.
  2. 보내는 사람(내 회사 Gmail)과 받는 사람(업체 이메일) 목록을 확인합니다.
  3. 템플릿을 고르고 필요하면 고칩니다.
    • 한 곳: 업체명·담당자·내 이름이 제목과 본문에 바로 채워집니다. 보이는 그대로 나갑니다.
    • 여러 곳: {업체명} {담당자} {영업자}가 업체마다 자동으로 바뀌어 나갑니다. "미리보기"로 첫 업체에 가는 메일을 확인하세요.
  4. 첨부 파일(제안서 등)을 추가하고 N곳에 보내기. 발송 결과에 업체별 받는 주소가 표시됩니다.
보낸 메일은 내 Gmail 보낸편지함에 남고, 업체 연락 기록에도 "보낸 사람 → 받는 사람"이 기록됩니다. 앱 비밀번호 같은 별도 설정은 필요 없습니다.

카톡·문자 보내기

  1. 업체를 눌러 상세 화면 → 카톡·문자.
  2. 문구가 업체에 맞게 자동으로 채워집니다. 문구 복사 → 카카오톡 열기 → 대화방에 붙여넣어 보냅니다.
  3. 휴대폰에서는 문자로 바로 보내기를 누르면 문구가 들어간 문자 앱이 열립니다.
카카오톡은 카카오 정책상 개인 카톡 자동 발송이 불가능해 '복사 → 붙여넣기' 방식입니다. 복사·문자를 누르면 연락 기록에 자동으로 남습니다.

팀장 확인 방법

팀원들의 저장 습관과 가망건 현황 보기

  • 팀 현황 탭: 누가 오늘 몇 건 저장했는지, 연락이 밀린 가망건이 몇 개인지
  • 가망건 목록 → 팀 전체: 팀 전체 가망건을 검색·필터. 업체를 누르면 연락 기록까지 확인
  • 구글 시트 원본: 엑셀처럼 정렬·필터·다운로드 가능 (가망건, 연락이력, 사용자 탭)

템플릿 문구, 하루 목표 같은 설정은 관리자 설정 가이드를 보세요.

메일이 보낸편지함에 없음팀장에게 받은 …/exec 링크로 접속했는지 확인하세요. 자기 자신에게 보낸 메일은 "받는사람: 나"로 표시됩니다.

화면이 예전 모습 그대로새로고침하세요. 관리자가 업데이트하면 같은 링크에 반영됩니다.
