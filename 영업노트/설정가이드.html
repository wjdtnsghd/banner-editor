처음 설치

관리자 1명이 한 번만 · 회사 구글 계정(@mymp.co.kr)으로 로그인한 상태에서 진행

1. 스프레드시트 만들기

  1. 구글 드라이브에서 팀 공유 폴더(예: 6팀 영업노트_db)를 엽니다.
  2. 빈 곳에서 마우스 오른쪽 클릭 → Google 스프레드시트 → 빈 스프레드시트.
  3. 왼쪽 위 "제목 없는 스프레드시트"를 눌러 이름을 영업노트_DB로 바꿉니다.

2. Apps Script에 코드 넣기

  1. 시트 메뉴 확장 프로그램 → Apps Script. 새 탭이 열립니다.
  2. 왼쪽 위 "제목 없는 프로젝트"를 눌러 영업노트로 바꿉니다. (처음 실행할 때 권한 창에 이 이름이 나옵니다)
  3. Code.gs: 기존 내용을 모두 지우고 Code.gs 파일 내용을 붙여넣습니다.
  4. Index.html: 왼쪽 파일 글자 옆 + → HTML → 이름에 Index 입력(확장자 없이) → 기본 내용을 모두 지우고 Index.html 파일 내용을 붙여넣습니다.
  5. Ctrl + S로 저장합니다. 제목 옆 "저장되지 않은 변경사항"이 사라져야 합니다.
자주 하는 실수
  • 맨 위 프로젝트 제목에 Index를 입력하면 파일이 만들어지지 않습니다. 반드시 파일 옆 + 버튼으로 만드세요.
  • Index.html에 Code.gs 내용을 붙여넣지 않았는지 확인하세요. 두 파일의 첫 줄은 이렇게 달라야 합니다.
Code.gs     →  /**  * 영업노트 – 팀 공용 가망건 관리 웹앱 …
Index.html  →  <!DOCTYPE html>

3. 처음 실행과 권한 허용

  1. 왼쪽에서 Code.gs를 누릅니다.
  2. 위쪽 ▷ 실행 · 디버그 오른쪽의 함수 선택칸을 눌러 getInitialData를 고릅니다. (처음에는 doGet이 선택되어 있습니다. 그대로 실행하면 시트가 만들어지지 않습니다)
  3. ▷ 실행 → "승인 필요" 창에서 권한 검토 → 회사 계정 선택.
  4. "Google에서 확인하지 않은 앱"이 나오면 고급 → 영업노트(으)로 이동(안전하지 않음) → 허용. 사내에서 만든 앱이라 나오는 안내입니다.
  5. 실행 로그에 실행이 완료됨이 나오면 시트로 돌아가 탭을 확인합니다.
가망건저장한 업체 목록
연락이력통화·메일·카톡 기록
템플릿기본 문구 6개 (이메일 3 · 카톡 3)
사용자앱에서 이름을 입력하면 채워짐

4. 웹 앱으로 배포

  1. Apps Script 오른쪽 위 배포 → 새 배포.
  2. 유형 선택 옆 ⚙️ → 웹 앱.
  3. 아래처럼 설정하고 배포:
    • 설명: 영업노트 v1
    • 다음 사용자 인증 정보로 실행: 웹 앱을 액세스하는 사용자
    • 액세스 권한이 있는 사용자: mymp.co.kr 내 모든 사용자
  4. 완료 창의 웹 앱 URL(https://script.google.com/a/macros/mymp.co.kr/s/…/exec)을 복사해 새 탭에서 엽니다.
  5. 이름을 입력하고 가망건 하나를 저장해 봅니다. 시트 가망건 탭에 한 줄이 생기면 설치 완료입니다.
실행 사용자는 꼭 "웹 앱을 액세스하는 사용자"로 두세요. "나"로 하면 팀원 모두의 메일이 관리자 Gmail로 나가고, 팀 현황도 한 사람으로 집계됩니다.
메일 발송은 받는 주소를 본인 주소로 해서 먼저 테스트하세요. 보낸편지함에 "받는사람: 나"로 남고 받은편지함에도 들어옵니다.

코드 업데이트

새 버전 코드를 받았을 때 · 링크는 그대로 유지

  1. 바뀐 파일(Code.gs 또는 Index.html)의 내용을 모두 지우고 새 내용을 붙여넣은 뒤 Ctrl + S.
  2. 배포 → 배포 관리를 엽니다.
  3. 오른쪽 위 ✏️ 연필(수정)을 누릅니다. 누르기 전에는 칸이 회색으로 잠겨 있고 배포 버튼도 눌리지 않습니다.
  4. 맨 위 버전을 눌러 새 버전을 고르고, 설명에 영업노트 v2처럼 적습니다.
  5. 배포 → 앱 화면을 새로고침합니다.
"새 배포"를 만들면 링크가 바뀝니다. 업데이트는 항상 "배포 관리 → 수정 → 새 버전"으로 하세요. 버전을 "버전 1" 그대로 두면 수정한 코드가 반영되지 않습니다.
Code.gs가 바뀌어 시트에 새 열이 필요한 경우(예: 연락시간)에는 앱을 처음 열 때 자동으로 맨 오른쪽에 추가됩니다. 기존 데이터는 그대로입니다.

대부분 시트나 Code.gs 맨 위에서 바꿉니다

팀원 공유

  1. 영업노트_DB 시트(또는 폴더)를 팀원에게 편집자로 공유합니다. 각자 본인 계정으로 실행되므로 편집 권한이 없으면 저장되지 않습니다.
  2. 웹 앱 URL과 팀원 가이드를 전달합니다. 팀원은 가이드의 "처음 설정"만 따라 하면 됩니다.
  3. 팀원은 링크를 열고 권한 허용 → 이름 입력 → 휴대폰 홈 화면에 추가하면 끝입니다. (팀원 처음 설정)
팀원이 편집자이므로 원본 시트를 직접 볼 수 있습니다. 팀 공용 영업 데이터라는 점을 안내해 주세요.
